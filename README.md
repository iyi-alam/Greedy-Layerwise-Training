Most of the deep neural network architectures have been trained without modifying the architecture while training. We believe that this is inefficient as every epoch requires multiple forward and backward propagations over the deep neural network. It would be more efficient if we can train a shallow network for a few epochs and incrementally add new layers on demand. Useful features would be learnt for much lower training cost during the initial phases. This approach would build the network incrementally to arrive at an optimally deep neural network architecture with minimal computation cost. If we formulate the problem of this neural architecture search as a sequence of discrete actions, we can train an RNN based neural network that implements an RL based policy optimization to optimally make decisions regarding addition of layer and halting the training.
